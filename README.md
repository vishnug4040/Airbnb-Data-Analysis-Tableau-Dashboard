# Airbnb Analysis Dashboard | Tableau

## Project Overview

Developed an interactive Tableau dashboard to analyze Airbnb listings, pricing patterns, room types, regional ratings, bed availability, and property types. The dashboard provides a consolidated view of listing performance and helps users explore geographic and historical pricing patterns.

## Objectives

* Analyze Airbnb listing prices across ZIP codes.
* Compare hosting counts across different room types.
* Identify regions with high review scores.
* Evaluate yearly changes in average listing prices.
* Explore price distribution across Airbnb listings.
* Compare bed availability across major regions.
* Analyze average prices by property type.

## Tools and Technologies

* **Tableau:** Interactive dashboard development and data visualization.
* **CSV:** Airbnb listing dataset.

## Dashboard Visualizations

### 1. Average Prices Based on ZIP Code

Uses a geographic map to visualize average Airbnb prices across ZIP codes and explore spatial pricing differences.

### 2. Hostings by Room Type

Compares listing counts across entire homes/apartments, private rooms, and shared rooms.

### 3. Top Regions by Ratings

Compares review-score totals across the leading regions to highlight differences in regional review activity.

### 4. Average Prices by Year

Displays changes in average listing prices over time, helping identify historical pricing trends.

### 5. Price Distribution

Uses a histogram to examine the distribution of listing prices and identify common price ranges.

### 6. Bed Availability by Top Regions

Compares bed availability across major regions to understand differences in accommodation capacity.

### 7. Average Price by Property Type

Compares average listing prices across property types, including lofts, townhouses, apartments, houses, condominiums, and other properties.

## Interactive Filters

* **Room Type:** Filter the dashboard by accommodation type.
* **Year:** Explore listing data for selected years.

These filters allow users to investigate different segments of the Airbnb dataset.
